# SellSnap

Reconstruction of the visible photo-to-marketplace listing concept. Captures product attributes and selected image previews locally, drafts a listing title and clear description, supports copy/download, and stores text drafts in browser localStorage. No image or listing is uploaded; selected image bytes are not stored after the page closes. The draft template does not determine market value or automatically post a listing.

The visible live site required ChatGPT sign-in, and the matching `AWEMISSIONS/SellSnap` repository had no usable source. This rebuild follows the App Hub description and does not recover the original implementation.
